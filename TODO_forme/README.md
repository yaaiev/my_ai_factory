# TODO_forme

本目录用于记录需要由你手动执行的命令或人工处理事项。

## 规则

- 每个待办文件使用日期前缀命名，例如：`2026-04-12.md`
- 我会把需要你执行的命令写在当天文件中
- 每天早上 11 点检查一次这些待办是否已经完成
- 如果某条已完成，我会删除对应条目
- 如果某个待办文件中的条目全部完成，我可以删除该文件
- 我只在 `TODO_forme/` 目录内拥有删除权限，其他目录仍不执行删除

## 建议格式

- `状态`：`待执行` / `已完成`
- `命令`：你需要执行的终端命令
- `原因`：为什么需要你手动做
- `完成标记`：我下次检查时用什么判断它已完成
