# memory topic 注册表

## 默认原则

- 新 memory 默认使用已注册 topic
- 事实、实现、研究、输出四类知识分开存放
- 过宽 topic 不继续扩写

## topic 清单

| topic | 用途 | 应包含什么 | 不应包含什么 | 状态 |
| ---- | ---- | ---- | ---- | ---- |
| seeds | Top 50 人物池与渠道映射 | 人物字段、来源映射、更新规则 | 临时实验日志 | 推荐 |
| sources | 采集源能力与限制 | API、RSS、频率、访问边界 | 结构化事件样本 | 推荐 |
| etl | 清洗、抽取、去重、聚类 | schema、规则、阈值、误差 | 投资观点 | 推荐 |
| graph | 实体关系与图谱边界 | 实体类型、关系类型、对齐策略 | 原始网页采集细节 | 推荐 |
| signals | 风险、机会、趋势与预警 | 打分逻辑、阈值、解释模板 | 原始 SQL 细节 | 推荐 |
| delivery | 日报、memo、预警产物 | 输出模板、栏目、读者约束 | 底层抓取重试细节 | 推荐 |

## 新增 topic 准入条件

- 新主题必须有明确边界
- 不能与已有主题同义
- 必须能被多个迭代周期复用
